## 📋 Descripción

NewsExplorer es una aplicación React que conecta con la API de NewsAPI para buscar noticias en tiempo real. Los usuarios pueden registrarse, iniciar sesión, buscar noticias por tema y guardar sus artículos favoritos.

## ✨ Funcionalidades

- Búsqueda de noticias por tema usando NewsAPI
- Registro e inicio de sesión de usuarios
- Guardar y eliminar artículos favoritos
- Página de artículos guardados con palabras clave
- Diseño responsive desde 320px
- Modales con cierre por X, overlay y tecla ESC

## 🛠 Tecnologías

- React 18 (CRA)
- CSS con metodología BEM
- NewsAPI
- localStorage para autenticación y artículos guardados

## 🚀 Instalación local

```bash
npm install
npm start
```

## ⚠️ Nota sobre la API de NewsAPI

La API de NewsAPI en su **plan gratuito** solo permite solicitudes desde `localhost`. Para que la búsqueda de noticias funcione en producción (Vercel, GitHub Pages, etc.) se requiere el **plan de pago Developer** ($449/mes) o el plan **Business**.

Para desarrollo local la API funciona perfectamente. En producción los artículos guardados y toda la funcionalidad de usuario siguen funcionando normalmente.

Más información: [newsapi.org/pricing](https://newsapi.org/pricing)
